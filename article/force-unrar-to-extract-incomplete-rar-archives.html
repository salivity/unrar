Force Unrar to Extract Incomplete RAR Archives

When dealing with split RAR archives, missing volumes typically cause the extraction process to halt and delete any partially recovered files. This guide explains how to bypass this limitation using the unrar command-line utility, forcing the software to retain broken or incomplete files so you can salvage intact data and partially extracted content from the available parts.

The Solution: The -kb Switch

By default, unrar automatically deletes any file that encounters an error or reaches a missing volume before extraction completes. To override this behavior, you must use the -kb (Keep Broken files) switch.

Run the following command in your terminal:

unrar x -kb archive.part01.rar
  • x: Extracts files with their full relative directory paths.
  • -kb: Instructs the program not to delete damaged or incomplete files.
  • archive.part01.rar: The first volume of the split archive (or whichever starting volume you possess).

Handling the Missing Volume Prompt

  1. Execute the command above pointing to your earliest available archive volume.
  2. The extraction will proceed normally until it requires a volume that is not present in the directory.
  3. The terminal will display an error or prompt you to specify the path to the missing volume (e.g., Cannot find archive.part02.rar).
  4. Press Enter without typing a path, or input Q (or Ctrl + C) to terminate the operation depending on the prompt version.

Because the -kb switch was provided, unrar will terminate while preserving everything it extracted up to the point of the missing archive.

Expected Results and Limitations

  • Independent Files: Any file fully contained within the available volumes prior to the missing split will extract completely undamaged.
  • Span Files: Any large file that spans across the missing volume boundary will be truncated at the point the missing data starts. Media files (such as audio or video) may still play up to the point of truncation using players like VLC, but compressed files, disk images, or executable programs will likely be unusable.
