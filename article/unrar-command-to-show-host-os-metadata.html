Unrar Command to Show Host OS Metadata

This guide explains how to view the originating host operating system metadata stored inside a RAR archive using the command line. By using the technical listing mode in the unrar tool, you can reveal internal archive headers—including the host OS on which the files were compressed—without having to extract any files.

To display the host OS metadata alongside other technical details, use the unrar lt command:

unrar lt archive.rar

Understanding the Command

  • unrar: The command-line utility for managing and unpacking RAR files.
  • l: Instructs the utility to list the contents of the archive.
  • t: Modifies the list command to output technical information in a multiline format.

When executed, unrar lt reads the archive headers and prints extended attributes for each entry, including the compression dictionary size, packing method, CRC checksum, and the Host OS (e.g., Unix, Windows, or MS-DOS).

Filtering Directly for the Host OS

If the archive contains numerous files and you only want to see the operating system information without scrolling through full technical logs, pipe the output to a text filter.

On Linux and macOS:

unrar lt archive.rar | grep -i "Host OS"

On Windows (Command Prompt / PowerShell):

unrar lt archive.rar | findstr /i "Host OS"

This output confirms the operating system environment where the RAR file was originally packaged, which helps verify permission models and path conventions before unpacking.
