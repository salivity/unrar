Extract Files Without Extension in UnRAR

This article explains how file extraction works with the UnRAR command-line utility, addressing whether a native switch exists to strip file extensions during extraction. It covers the technical limitations of UnRAR regarding filenames, clarifies the common confusion between file paths and file extensions, and provides straightforward scripting solutions to remove extensions immediately after extraction.

Does UnRAR Have a Switch to Remove Extensions?

The short answer is no. UnRAR does not have a built-in switch or parameter to strip or alter the file extensions of archived files during extraction. By design, UnRAR extracts files preserving the exact filenames and extensions stored within the RAR archive to ensure file integrity.

Common Confusion: Extensions vs. Directory Paths

Users often confuse stripping file extensions with stripping directory paths.

If your goal is to extract files without their enclosing folders or directory structure, UnRAR does provide commands and switches for this:

  • unrar e archive.rar: The e command extracts all files into the current working directory, ignoring any internal folder paths stored in the archive.
  • -ep switch: Used with the x command (e.g., unrar x -ep archive.rar) to exclude paths from filenames, flattening the output into a single destination folder.

Neither of these options will remove the file format extension (such as .txt, .jpg, or .dat).

How to Extract Files and Remove Extensions

Because UnRAR cannot alter file extensions directly, the standard solution is to extract the files first and then use a simple shell command or script to strip the extensions.

Linux and macOS (Bash)

Extract the archive into a dedicated directory and remove extensions using standard shell expansion:

# 1. Extract files ignoring folder paths
unrar e archive.rar output_dir/

# 2. Navigate to the folder and strip file extensions
cd output_dir/
for file in *.*; do
    [ -f "$file" ] && mv "$file" "${file%.*}"
done

The parameter expansion ${file%.*} removes the final dot and any trailing characters from the filename.

Windows (PowerShell)

On Windows systems, you can achieve the same result using a PowerShell pipeline after extracting:

# 1. Extract files
unrar e archive.rar C:\output_dir\

# 2. Rename extracted files without extensions
Get-ChildItem -Path "C:\output_dir" -File | ForEach-Object {
    $newName = [System.IO.Path]::GetFileNameWithoutExtension($_.Name)
    Rename-Item -Path $_.FullName -NewName $newName
}

This workflow ensures files are extracted correctly while achieving the desired outcome of removing the extension from each extracted file.
