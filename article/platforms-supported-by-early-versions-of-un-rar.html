Platforms Supported by Early Versions of UnRAR

This article covers the operating systems and environments officially supported by early versions of UnRAR following the archive format's debut in the 1990s. When Eugene Roshal introduced the RAR format, cross-platform extraction was prioritized, leading to official binaries and portable source code targeting MS-DOS, OS/2, early 32-bit Windows, and a wide array of Unix and Unix-like operating systems.

MS-DOS

MS-DOS was the native development environment for the earliest releases of RAR and UnRAR starting in late 1993 (RAR 1.30 through RAR 1.5x). Initial 16-bit real-mode binaries were quickly supplemented by 32-bit DOS protected-mode versions, which leveraged DOS extenders to handle larger files and decompression dictionaries.

IBM OS/2

IBM OS/2 was one of the first non-DOS operating systems to receive official support. During the mid-1990s (around RAR 1.53 and version 2.0), Eugene Roshal released native 32-bit command-line utilities specifically compiled for OS/2 2.x and OS/2 Warp.

Windows (Win32)

With the launch of RAR 2.0 in the mid-1990s, native 32-bit console versions were officially introduced for Windows NT and Windows 95. These console utilities allowed command-line extraction before the full WinRAR graphical interface became the standard Windows client.

Unix and Unix-Like Systems

To facilitate adoption across server and academic environments, Roshal released a portable, open-source C++ extraction package known as the UnRAR source code. RARLAB officially maintained makefiles and pre-compiled binaries for several major Unix platforms:

  • Linux (x86): The primary Unix target, distributed as native static and dynamic ELF binaries.
  • FreeBSD: Maintained alongside Linux for BSD-based environments.
  • SunOS and Solaris: Supported on SPARC and x86 architectures.
  • HP-UX: Provided for PA-RISC systems in enterprise deployments.
  • SGI IRIX: Maintained for Silicon Graphics workstations.
  • IBM AIX: Provided for RS/6000 hardware.

Secondary and Community-Maintained Ports

Because the UnRAR decompression source code was made freely redistributable, early versions were also officially ported or recognized by RARLAB for specialized computing platforms. These included Commodore Amiga (AmigaOS 68k and PowerPC), BeOS, and Classic Mac OS, ensuring that files created with early versions of the format could be extracted across virtually every contemporary desktop architecture.
