What Happens When Running Unrar Without Arguments

Running the unrar command in a terminal without specifying any arguments is entirely safe and serves as a trigger for the program's built-in help manual. Rather than executing an extraction, modifying files, or causing a system error, the utility simply outputs its version information, proper command-line syntax, and a complete directory of available commands and option switches.

The Standard Output

When you type unrar and press Enter, the utility prints a structured text guide directly into your terminal window. The output generally consists of three main sections:

  1. Header and Version Details: Shows the program name, version number, copyright notice (Alexander Roshal), and whether the build is freeware.
  2. Usage Syntax: Displays the standard format required to execute commands, typically written as: 
    Usage: unrar <command> -<switch 1> -<switch N> <archive> <files...> <path_to_extract\>
  3. List of Commands and Switches: Outlines the individual letter commands used to dictate operations, alongside switches used to modify their behavior.

Primary Commands Displayed

The output details the primary operational commands you can pair with unrar, including:

  • e: Extract files to the current directory, ignoring the archive's internal folder structure.
  • x: Extract files with their full relative paths, preserving the original directory hierarchy.
  • l: List the contents of an archive without unpacking anything.
  • t: Test the integrity of archive files to verify they are not corrupted.
  • v: Verbosely list archive contents with technical metadata.
  • p: Print file contents directly to standard output (stdout).

Common Switches Displayed

Below the commands, the terminal output lists configuration flags (switches) preceded by a hyphen (-). Key switches include:

  • -p[password]: Specify a password to decrypt password-protected archives.
  • -r: Recurse through subdirectories.
  • -y: Assume "yes" on all interactive queries (such as overwrite prompts).
  • -o+: Automatically overwrite existing files during extraction.
  • -o-: Do not overwrite existing files.

System Impact and Return Code

Running unrar alone makes zero changes to your file system. It does not scan your drive, create directories, or delete data. In scripting environments, the command will exit immediately after printing the help text, returning an exit code that indicates the utility exited without processing an archive. To perform an actual task after viewing this menu, you must supply at least one command letter and an archive target, such as unrar x archive.rar.
