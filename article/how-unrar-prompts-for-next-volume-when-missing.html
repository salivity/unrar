How Unrar Prompts for Next Volume When Missing

When extracting multi-part RAR archives, the unrar utility processes files sequentially and pauses if a required continuation volume is absent from the target directory. Instead of failing immediately, interactive terminal sessions prompt the user to provide the missing file or point to a new directory location. This article covers the exact prompt format used by unrar, the input actions required to resume extraction, and how automated flags influence this behavior.

The Interactive Volume Prompt

When unrar reaches the end of an archive part (such as .part1.rar or .r00) and the subsequent file (such as .part2.rar or .r01) is missing, it halts the extraction process and prints a prompt directly to the standard output:

Cannot find volume <filename.part2.rar>
Insert disk with this volume and press [Enter],
or enter new path to volume, or [Esc] to exit:

(Note: Older versions or command-line variants may display "Insert disk with volume..." reminiscent of floppy disk prompts).

User Actions at the Prompt

When this prompt appears, the user has three primary ways to respond:

  1. Move or Download the File, Then Press Enter
    If you have located or downloaded the missing volume, you can place it directly into the directory where unrar is currently working. Once the file is in place with the expected name, simply press the Enter key without typing anything. The utility re-checks the current directory, detects the file, and seamlessly continues the extraction.

  2. Specify a New File Path
    If the missing volume resides in another directory, drive, or mounted share, you can type the absolute or relative path to that file (or directory) directly into the terminal prompt and press Enter. For example:

    • On Linux/macOS: /home/user/downloads/archive.part2.rar or /mnt/storage/
    • On Windows: D:\Archives\archive.part2.rar or D:\Archives
      unrar will locate the volume at the designated path and proceed without requiring you to move the file.

  3. Abort the Process
    To cancel the extraction, press the Esc key (or issue an interrupt signal via Ctrl + C). The process will terminate, leaving any partially extracted files according to your command-line configuration (by default, incomplete files are deleted unless the -kb switch is active).

Non-Interactive and Scripted Behavior

If unrar is run in an automated script, background service, or with specific flags, the interactive prompt may be suppressed:

  • The -y Switch (Assume Yes): Running unrar x -y archive.part1.rar suppresses interactive queries. If the next volume is missing, unrar will not prompt; it will terminate with an error code indicating a missing volume.
  • Standard Input Redirection: If unrar detects that standard input (stdin) is closed or not attached to an interactive TTY, it will automatically abort the extraction rather than hanging on the missing volume prompt.
