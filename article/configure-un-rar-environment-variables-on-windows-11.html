Configure UnRAR Environment Variables on Windows 11

Configuring environment variables for UnRAR on Windows 11 allows you to run extraction commands directly from the Command Prompt or PowerShell without specifying the full executable path. This guide provides a straightforward, step-by-step process to locate the UnRAR executable, add its directory to your Windows system PATH, and verify that the command works properly from any terminal window.

Step 1: Locate the UnRAR Directory

Before modifying your system variables, find where UnRAR.exe is installed on your computer:

  1. Open File Explorer (Windows Key + E).
  2. If you installed WinRAR, navigate to the default installation folder: 
    C:\Program Files\WinRAR
    (If you downloaded the standalone UnRAR command-line utility from RARLAB, open the custom folder where you extracted it).
  3. Verify that UnRAR.exe is present in that folder.
  4. Click the address bar in File Explorer, copy the full path (e.g., C:\Program Files\WinRAR), and keep it handy.

Step 2: Open System Environment Variables

  1. Press Windows Key + S to open the Windows 11 search bar.
  2. Type Edit the system environment variables and press Enter.
  3. In the System Properties window that appears, ensure you are on the Advanced tab.
  4. Click the Environment Variables... button near the bottom right.

Step 3: Add UnRAR to the Path Variable

  1. Under the System variables section (the lower box), scroll down and select the variable named Path.
  2. Click the Edit... button.
  3. In the new window, click the New button on the right side.
  4. Paste the path you copied in Step 1 (for example, C:\Program Files\WinRAR).
  5. Click OK to close the Edit Environment Variable window.
  6. Click OK on the Environment Variables window, and then click OK on the System Properties window to apply the changes.

Step 4: Verify the Configuration

  1. Press Windows Key + R, type cmd, and press Enter to open the Command Prompt. (If you already had a terminal open, close and reopen it so it loads the updated variables).
  2. Type the following command and press Enter: 
    unrar
  3. If configured correctly, the terminal will display the UnRAR copyright information and a list of available command options and switches.
