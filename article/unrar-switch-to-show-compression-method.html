Unrar Switch to Show Compression Method

Inspecting the internal metadata of RAR archives from the command line is essential for diagnosing archive performance, checking encryption, and verifying storage efficiency. This guide explains which command switch in unrar displays the specific compression method applied to individual files inside a RAR archive.

To display the compression method for each file within an archive, you must use the v (verbose list) command or the vt (technical list) command. Unlike the standard list command (unrar l), which only displays basic file attributes and raw sizes, the verbose mode reveals extended technical details, including the compression algorithm level and packing ratios.

Using the Verbose Command (v)

Run the following command in your terminal:

unrar v archive.rar

When executed, unrar outputs a multi-column table listing file details. In standard versions of RAR and UNRAR, this table includes columns for packed size, compression ratio, file attributes, CRC checksums, and the compression method (often abbreviated under "Meth" or detailed in the summary row per entry).

Getting Detailed Technical Information (vt)

For a comprehensive per-file breakdown that explicitly names the compression method on its own dedicated line, use the vt switch:

unrar vt archive.rar

This command switches the output from a condensed table to a detailed, block-based listing for every single file. Within each file's block, look for the Method field.

The output identifies the compression level used during archiving, typically represented as:

  • m0 (Store / No compression)
  • m1 (Fastest)
  • m2 (Fast)
  • m3 (Normal)
  • m4 (Good)
  • m5 (Best)

Additionally, the vt output details the RAR format version (e.g., RAR 4.x or RAR 5.0) and whether the file is part of a solid archive block.
