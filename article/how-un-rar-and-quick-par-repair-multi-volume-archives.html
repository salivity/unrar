How UnRAR and QuickPar Repair Multi-Volume Archives

Managing split archives often leads to missing or corrupted parts, preventing extraction. While UnRAR specializes strictly in unpacking RAR files, it cannot reconstruct missing data on its own. QuickPar bridges this gap by using Parchive (PAR2) parity files to detect data corruption, reconstruct damaged segments, and rebuild missing multi-volume RAR files. Once QuickPar restores the missing volumes, UnRAR can successfully unpack the complete, undamaged archive.

The Division of Roles

UnRAR and QuickPar perform two distinct phases of the data recovery and extraction pipeline:

  • QuickPar (Parity and Repair): Operates on the mathematical redundancy layer using Reed-Solomon coding. It evaluates the integrity of the data blocks within the split volumes against .par2 parity sets. If files are corrupted or missing, QuickPar uses parity blocks to recalculate and recreate the exact original RAR volumes.
  • UnRAR (Decompression and Assembly): Operates on the archive container layer. It traverses the sequential volumes (e.g., .part01.rar, .part02.rar) to extract the compressed contents. UnRAR requires every single block across the multi-volume set to pass CRC checksum validation to extract the files without errors.

The Repair and Extraction Workflow

The integration between the two utilities follows a linear pipeline:

  1. Failure Detection: When extracting a multi-volume archive, UnRAR halts if a volume is missing or fails its internal CRC check, throwing a checksum or unexpected end-of-file error.
  2. Parity Verification: The user or automated script loads the corresponding .par2 file into QuickPar. QuickPar scans the existing RAR volumes, slicing them into uniform data blocks and matching their hashes against the PAR2 index.
  3. Volume Reconstruction: QuickPar calculates how many blocks are missing or corrupt. If the available parity blocks equal or exceed the missing data blocks, QuickPar regenerates the exact missing .rar or .partXX.rar files to disk.
  4. Hand-Off to UnRAR: With all volumes physically present and validated, UnRAR is executed against the primary archive file (such as archive.part01.rar). UnRAR processes the restored contiguous data stream and extracts the target files without interruption.

Automation and Command-Line Integration

While the standard QuickPar interface is a Windows GUI, multi-volume workflows are frequently automated via scripts or Usenet download managers (such as SABnzbd or NZBGet). In these environments, the GUI QuickPar logic is mirrored by its command-line equivalent, par2cmdline.

The automated pipeline executes verification commands first. If repairs are needed, the tool repairs the damaged RAR volumes before automatically triggering the unrar x command. If QuickPar is used manually, its options allow it to monitor folders, automatically repair when enough parity is present, and optionally delete unused recovery blocks once UnRAR confirms a successful extraction.
