Extract RAR Split Across Multiple Discs Using Unrar

Extracting a multi-volume RAR archive spanning several optical discs (CDs, DVDs, or Blu-rays) using the command-line utility unrar can be achieved in two ways: extracting directly from the optical drive with manual disc swapping, or copying all volume files to a local storage drive first. This guide explains how to properly execute the unrar command for multi-disc archives, navigate disc-swapping prompts, and avoid common optical drive mounting issues.

Method 1: Extract Directly from the Optical Drive

You can extract the archive directly without using extra hard drive space for the compressed parts. unrar will pause and prompt you whenever it requires the next volume.

  1. Insert the First Disc: Insert the disc containing the first volume (e.g., archive.part01.rar or archive.r00) into your drive and ensure it is mounted.
  2. Run the Extraction Command: Open your terminal and run the extraction command, pointing to the archive on the disc and specifying an output directory on your local drive: 
    unrar x /media/username/DISC1/archive.part01.rar /path/to/destination/
    Note: Always use x instead of e to preserve the original directory structure of the files.
  3. Swap Discs When Prompted: When unrar finishes reading the first volume, it will display a message stating that the next volume is required: 
    Cannot find volume /media/username/DISC1/archive.part02.rar
Insert disk with this volume and press Enter or type the new path:
  4. Eject and Mount the Next Disc: Eject the current disc, insert the next disc, and wait for the system to mount it.
  5. Provide the New Path: If the mount point changes (for example, if the second disc has a different label like DISC2), type the full path to the next file (e.g., /media/username/DISC2/archive.part02.rar) and press Enter. If the mount path remains identical, simply press Enter.
  6. Repeat this process until all discs have been processed and the extraction is complete.

Method 2: Copy Files to a Local Directory (Recommended)

Extracting directly from optical media can fail if your operating system locks the drive tray during active process execution. The most reliable method is staging the archive files locally:

  1. Create a Temporary Folder: Create a single directory on your hard drive or SSD: 
    mkdir ~/rar_temp
  2. Copy All Parts: Insert each disc sequentially and copy all the RAR volume files (.part01.rar, .part02.rar, etc.) into that single temporary folder.
  3. Extract the Archive: Navigate to the folder and run unrar on the first volume: 
    cd ~/rar_temp
unrar x archive.part01.rar /path/to/destination/
    unrar will automatically detect and process every subsequent volume in the folder without pausing.
  4. Clean Up: Delete the temporary directory once the extraction is verified: 
    rm -r ~/rar_temp

Handling Locked Drive Trays on Linux

If using Method 1 on Linux, your system may prevent you from ejecting the disc while unrar is waiting. If the drive is locked:

  1. Open a second terminal window.
  2. Force an unmount using: 
    sudo umount -l /media/username/DISC1
  3. Eject the disc: 
    eject
  4. Insert the new disc, mount it, and return to the first terminal to continue extraction.
