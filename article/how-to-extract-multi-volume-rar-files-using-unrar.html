How to Extract Multi-Volume RAR Files Using Unrar

This guide explains how to extract multi-volume (split) RAR archives using the unrar command-line utility. Multi-volume archives split large files across multiple pieces, such as .part1.rar, .part2.rar, or older formats like .rar, .r00, and .r01. You will learn the exact command syntax required to decompress these sets, understand how file naming affects extraction, and discover key flags for preserving directory structures and specifying destination paths.

1. Ensure All Archive Parts Are Present

Before running any command, all parts of the split archive must be located in the same directory. Multi-volume archives typically follow one of two naming schemes:

  • Newer format: archive.part1.rar, archive.part2.rar, archive.part3.rar
  • Older format: archive.rar, archive.r00, archive.r01

If even one file part is missing, corrupted, or in a different folder, the extraction process will fail.

2. Basic Extraction Command

To extract a multi-part archive, you only need to run unrar against the first file in the sequence. The utility automatically detects and processes all subsequent volumes.

Use the x switch to extract files while preserving the original directory structure:

unrar x archive.part1.rar

For older naming schemes, target the primary .rar file:

unrar x archive.rar

Note: Avoid using unrar e unless you want all files dumped into a single flat directory, ignoring any folders saved inside the archive.

3. Extracting to a Specific Directory

By default, files are extracted to your current working directory. To unpack the files into a different folder, append the destination path to the end of the command:

unrar x archive.part1.rar /path/to/destination/

Ensure the destination path ends with a trailing slash (/). If the destination folder does not exist, unrar will create it automatically.

4. Useful Flags for Multi-Volume Archives

You can combine additional switches with the extract command to automate the process:

  • Extract with a password:
    If the archive is encrypted, supply the password directly or wait for the interactive prompt: 
    unrar x -pMySecretPassword archive.part1.rar
  • Overwrite existing files without prompting: 
    unrar x -o+ archive.part1.rar
  • Skip existing files: 
    unrar x -o- archive.part1.rar
  • Test archive integrity without extracting:
    Verify all volumes are intact before unpacking: 
    unrar t archive.part1.rar
