Unrar Broken Multi-Volume Sequence Error

When extracting split RAR archives using the unrar command-line utility, encountering a missing or corrupted file in the set will halt the extraction process. This guide details the exact error messages unrar displays when a multi-volume sequence is broken, why these errors trigger, and how to address them.

When a multi-volume RAR sequence is broken—such as when a piece is missing, out of order, or renamed incorrectly—unrar outputs the following error message:

Cannot find volume <archive_name>.partX.rar

Depending on the specific command flags used, unrar may pause and prompt for the missing file location:

Insert disk with <archive_name>.partX.rar

If the prompt is skipped, aborted, or executed in non-interactive batch mode, unrar terminates the process and outputs:

Cannot open <archive_name>.partX.rar
Unexpected end of archive
Total errors: 1

If a volume is physically present but truncated or damaged mid-stream, unrar instead produces:

CRC failed in <extracted_file>
Unexpected end of archive
Total errors: 1

Causes of the Error

  1. Missing Part: A volume file (such as .part2.rar or .r01) is missing from the target directory.
  2. Naming Mismatch: The naming scheme across volumes is inconsistent (for example, mixing archive.part1.rar with archive.part02.rar).
  3. Incomplete Download: The subsequent volume was only partially downloaded or corrupted during transfer.

How to Resolve the Issue

  • Verify Naming Continuity: Ensure all parts follow a consistent naming structure (e.g., file.part1.rar, file.part2.rar or file.rar, file.r00, file.r01).
  • Keep Files in One Directory: Ensure all volume files reside in the same folder from which the extraction command is run.
  • Check Missing Volumes: Identify which volume number unrar failed to find and re-download or reconstruct that specific file using available recovery volumes (.rev files) or PAR2 recovery sets.
