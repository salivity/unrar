Difference Between Unrar t and v Commands

The command-line tool unrar provides distinct commands to inspect and verify archives without extracting files to your storage drive. While both unrar t and unrar v interact with an archive without saving files to the disk, they serve entirely different purposes: unrar t tests the archive for corruption by decompressing the data in memory and validating checksums, whereas unrar v provides a verbose list of the files inside the archive along with their technical metadata.

The unrar t Command: Test Archive

The t command stands for Test. It is used to verify the integrity of the files contained within a RAR archive.

  • Function: When you run unrar t archive.rar, the program reads the archive and decompresses the data in memory.
  • Integrity Checking: It computes the checksum (CRC32 or BLAKE2) of the decompressed data and compares it against the checksum stored in the archive headers.
  • Disk Usage: No files are written to the disk during this process.
  • Performance: It takes longer to complete than listing commands because the entire data payload must be processed and decoded.
  • Use Case: Determining whether an archive is damaged, incomplete, or corrupted before attempting a full extraction.

If the archive is intact, the command ends with a confirmation message (such as "All OK"). If any file is corrupt, it flags the specific file with a checksum error.

The unrar v Command: Verbosely List Archive

The v command stands for Verbosely list. It is an informational tool used to inspect what is stored inside the archive.

  • Function: When you run unrar v archive.rar, the program reads only the headers of the archive.
  • Information Displayed: It prints a detailed table to the terminal, including:
    • File paths and file names
    • Original (uncompressed) file size
    • Compressed (packed) file size
    • Compression ratio
    • Date and time of last modification
    • File attributes and permissions
    • Stored CRC checksum
    • Host operating system
  • Integrity Checking: It does not decompress the file data or verify that the archive content is uncorrupted. It only confirms that the archive headers are readable.
  • Performance: Extremely fast, as it does not unpack or process compressed streams.
  • Use Case: Checking the contents, directory structure, or compression details of an archive without extracting it.

Key Differences

Feature unrar t (Test) unrar v (Verbosely List)
Primary Goal Check data integrity Inspect contents and metadata
Data Processing Decompresses payload in memory Reads header data only
Execution Speed Slower (scales with file size) Fast (instantaneous for most archives)
Detects Corrupt Data Yes No (only detects damaged headers)
Output Type Pass/fail status per file Detailed table of file attributes

In summary, use unrar t when you need to know if an archive is fully functional and free of data corruption, and use unrar v when you simply need to see what files are inside and inspect their metadata.
