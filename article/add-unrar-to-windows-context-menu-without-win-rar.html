Add Unrar to Windows Context Menu Without WinRAR

This article explains how to integrate RAR archive extraction directly into the Windows right-click context menu without installing the full WinRAR software suite. By pairing the official, standalone, freeware UnRAR.exe utility from RARLab with a simple Windows Registry tweak, users can add lightweight "Extract Here" and "Extract to Subfolder" options to File Explorer.

Step 1: Obtain the Standalone UnRAR Utility

You do not need the full WinRAR setup to extract archives. RARLab distributes a free command-line tool called UnRAR.exe.

  1. Download the command-line UnRAR utility package from the official RARLab download repository.
  2. Extract the unrar.exe file from the downloaded archive or installer.
  3. Move unrar.exe into a permanent directory that is accessible system-wide. Placing it in C:\Windows\System32 or C:\Windows allows you to call the executable directly without specifying a full directory path in commands. Alternatively, place it in a custom folder such as C:\Tools\UnRAR\.

Step 2: Create a Registry Script for the Context Menu

To add right-click options for .rar files, create a .reg file that links the file type to your unrar.exe executable.

  1. Open Notepad.
  2. Paste the following registry configuration:
Windows Registry Editor Version 5.00

; Add "Extract Here" to the context menu
[HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarHere]
@="Extract Here"

[HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarHere\command]
@="\"C:\\Windows\\unrar.exe\" x -y \"%1\""

; Add "Extract to Subfolder" to the context menu
[HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarFolder]
@="Extract to Subfolder"

[HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarFolder\command]
@="\"C:\\Windows\\unrar.exe\" x -ad -y \"%1\""

Note: If you stored unrar.exe somewhere other than C:\Windows\, update the path inside the quotes, using double backslashes (\\) to escape directory separators.

  1. In Notepad, click File > Save As.
  2. Set the Save as type dropdown to All Files (.).
  3. Name the file AddUnrarMenu.reg and save it to your desktop or downloads folder.

Step 3: Apply the Registry Changes

  1. Double-click the saved AddUnrarMenu.reg file.
  2. Click Yes when prompted by User Account Control (UAC).
  3. Click Yes to confirm merging the registry values, then click OK.

Explanation of the Parameters

  • x: Tells the program to extract files while preserving the original folder structure.
  • -y: Automatically answers "yes" to prompts (such as overwriting files).
  • -ad: Appends the archive name to the destination folder to prevent cluttering the current directory with extracted contents.
  • "%1": Represents the path of the archive selected in the Windows context menu.

How to Remove the Context Menu Entries

If you wish to remove these entries later, create another .reg file containing the following code and run it:

Windows Registry Editor Version 5.00

[-HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarHere]
[-HKEY_CLASSES_ROOT\SystemFileAssociations\.rar\shell\UnrarFolder]
