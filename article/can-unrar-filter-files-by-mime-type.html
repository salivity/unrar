Can Unrar Filter Files by MIME Type?

The command-line utility unrar cannot natively filter files by their MIME type during the extraction process. Because the RAR archive format only stores metadata such as filenames, extensions, timestamps, and permissions—not explicit MIME types—unrar lacks the built-in capability to inspect magic bytes or content signatures before extraction. However, users can achieve this behavior either by filtering by file extensions directly within unrar or by pairing unrar with Unix utilities like file and shell scripting.

Why Native MIME Filtering Is Not Supported

A MIME type (such as image/png or application/pdf) is typically determined by reading a file's initial bytes (magic numbers) rather than its filename. The unrar tool only reads archive file headers prior to decompression. To identify a file's actual MIME type, the data would have to be decompressed and analyzed in memory, a feature that unrar does not implement.

Alternative 1: Filtering by File Extension

If your files have standard extensions that correspond to the desired MIME type, you can use unrar's built-in wildcard pattern matching to extract only specific file types:

unrar e archive.rar *.pdf

To extract files while preserving the directory structure:

unrar x archive.rar *.jpg *.jpeg

This method filters based strictly on the filename, which works in the majority of standard use cases.

Alternative 2: Scripting Real MIME Type Filtering

If you must verify the true MIME type regardless of file extension, you can extract the archive to a temporary directory and use the file command to filter and keep only matching files.

Here is a Bash script example that extracts only files with the MIME type application/pdf:

#!/usr/bin/env bash

ARCHIVE="archive.rar"
TARGET_DIR="./extracted_files"
MIME_TARGET="application/pdf"
TEMP_DIR=$(mktemp -d)

# Extract everything to a temporary location
unrar x "$ARCHIVE" "$TEMP_DIR/"

mkdir -p "$TARGET_DIR"

# Find and move only files matching the target MIME type
find "$TEMP_DIR" -type f | while read -r filepath; do
    detected_mime=$(file --mime-type -b "$filepath")
    if [ "$detected_mime" = "$MIME_TARGET" ]; then
        mv "$filepath" "$TARGET_DIR/"
    fi
done

# Clean up remaining files
rm -rf "$TEMP_DIR"

This approach ensures that files are filtered according to their true content type rather than relying solely on file extensions.
