Extract RAR Files Without Subfolders Using Unrar

When extracting a RAR archive, the standard command often preserves the original directory tree, recreating multiple nested subfolders on your system. This article explains how to force the unrar command-line utility to ignore the archive's internal folder paths, flattening the structure so that every file is dumped directly into a single target directory.

The Solution: Use the e Command Instead of x

The standard unrar tool provides two distinct commands for extracting files:

  • unrar x (Extract with full path): Recreates the exact folder hierarchy stored inside the archive.
  • unrar e (Extract excluding paths): Ignores all internal paths and extracts every file directly into the specified destination folder.

To ignore the path structure and dump all files into your current working directory, run:

unrar e archive.rar

Extracting to a Specific Folder

If you want to dump all files into a specific directory rather than your current one, provide the destination path at the end of the command:

unrar e archive.rar /path/to/destination/

Note: Ensure the destination path ends with a trailing slash (/) so unrar recognizes it as a directory.

Handling Duplicate File Names

Because flattening an archive places files from different subfolders into a single location, files with identical names will cause collisions. By default, unrar prompts you for an action when a file conflict occurs. You can automate this behavior using switches:

  • Automatically overwrite existing files: 
    unrar e -o+ archive.rar /path/to/destination/
  • Skip files that already exist: 
    unrar e -o- archive.rar /path/to/destination/
  • Automatically rename duplicate extracted files: 
    unrar e -or archive.rar /path/to/destination/
