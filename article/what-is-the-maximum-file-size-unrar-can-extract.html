What Is the Maximum File Size Unrar Can Extract?

This guide covers the maximum file size limits for extracting archives using unrar. In modern computing environments, unrar can theoretically extract files up to 16 Exabytes (EiB) under the RAR 5.0 specification. However, practical extraction limits are determined by the archive format version, whether a 32-bit or 64-bit version of unrar is used, and the file system of the destination drive.

Archive Format Limits

The format used to create the archive dictates the fundamental maximum file size:

  • RAR 5.0 Format: The current standard RAR format supports individual extracted file sizes up to approximately 16 Exabytes (\(2^{64} - 1\) bytes). The archive itself also supports multi-volume files up to this same limit.
  • RAR 4.x (Legacy) Format: The older RAR specification supports individual files up to 8.58 billion gigabytes (approximately 8 Exabytes).

From a software protocol standpoint, modern RAR specifications present virtually no restriction for consumer or enterprise file sizes.

32-bit vs. 64-bit Unrar Binaries

The binary architecture of the unrar utility running on your system introduces distinct limits:

  • 64-bit Unrar: Fully supports 64-bit integer file pointers. It can extract archives up to the full 16 Exabyte architectural limit, constrained only by storage capacity.
  • 32-bit Unrar: Older 32-bit builds compiled without Large File Support (LFS) fail when extracting files larger than 2 GB or 4 GB due to 32-bit signed integer limits. Modern 32-bit builds compiled with LFS can handle larger files, but 64-bit versions are recommended for archives over 4 GB.

File System Limitations

Regardless of what unrar can process, the target drive's file system determines the maximum single-file size that can actually be written to disk:

  • FAT32: 4 GB maximum file size. Any extraction of a file larger than 4 GB will fail with a disk write error, even if there is free space available.
  • exFAT: 128 Petabytes (PB) maximum file size.
  • NTFS: 16 Terabytes (TB) to 256 TB, depending on the allocation unit size.
  • ext4 (Linux): 16 TB maximum file size.
  • APFS (macOS): 8 Exabytes maximum file size.

Summary

For modern 64-bit systems writing to standard file systems (such as NTFS, ext4, or APFS), unrar can extract files up to 16 Exabytes for RAR5 archives and 8 Exabytes for legacy RAR archives. In typical day-to-day scenarios, the only real bottleneck is the available storage space and the file system limit of the target storage drive.
