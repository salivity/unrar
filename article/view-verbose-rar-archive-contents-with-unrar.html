View Verbose RAR Archive Contents with Unrar

Viewing the detailed contents of a RAR archive without extracting it is essential for checking file integrity, compression ratios, and embedded metadata. Using the command-line utility unrar, you can retrieve comprehensive technical information about every file within an archive by applying specific list switches. This guide explains the exact commands needed to inspect detailed archive properties, compare basic and verbose outputs, and filter specific file attributes directly from your terminal.

The Primary Verbose Command: unrar v

To display verbose information for an entire archive, use the v command switch followed by the path to your RAR file:

unrar v archive.rar

This command outputs a detailed table for each compressed file containing:

  • Attributes: File permissions and system attributes (e.g., read-only, hidden, directory status).
  • Size: The uncompressed size of the file in bytes.
  • Packed: The compressed size of the file within the archive.
  • Ratio: The compression percentage achieved.
  • Date & Time: Timestamp of the file's last modification.
  • Checksum: The CRC32 checksum for verifying file integrity.

Detailed Technical Information: unrar vt

For an even deeper breakdown of technical metadata, combine the verbose flag with the t modifier:

unrar vt archive.rar

The technical verbose mode extends the output to show:

  • The host operating system where the archive was generated.
  • The compression method and dictionary size used.
  • Encryption status (whether headers or files are password-protected).
  • NTFS streams and extended file system attributes (if stored).

Key Differences Between l and v

  • unrar l archive.rar (Standard List): Displays a simplified, truncated list showing only basic filenames, sizes, and timestamps. Long file paths may be truncated to fit terminal widths.
  • unrar v archive.rar (Verbose List): Displays full, unabbreviated file paths along with complete CRC32 data and extended file properties.

Filtering the Verbose Output

If an archive contains hundreds of files, you can target specific items or pipe the output to pagination tools:

  • View verbose details for a specific file:

    unrar v archive.rar document.pdf

  • View details using wildcards:

    unrar v archive.rar *.png

  • Scroll through long lists:

    unrar v archive.rar | less

  • Suppress archive comments for cleaner output:

    unrar v -c- archive.rar
