How to Unrar Specific Volume of Solid Archive

This guide explains how to extract files from multi-volume solid RAR archives using the unrar command-line tool. You will learn the technical constraints of solid compression, the exact commands required to extract individual files, and how to handle scenarios where you only have access to specific volumes of a split archive.

The Nature of Solid Multi-Volume Archives

Before attempting extraction, it is essential to understand how solid RAR archives work. In a standard archive, each file is compressed independently. In a solid archive, all files are merged into a single continuous data stream before compression. This improves compression ratios significantly, but it introduces a major dependency: decompressing any file later in the stream requires the decompression dictionary built from the data preceding it.

Because of this design, you cannot independently decompress a middle or late volume (such as part03.rar) of a solid archive without providing the preceding volumes (part01.rar, part02.rar).

Standard Extraction: Extracting Specific Files

If you possess all volumes and want to extract a specific file located within a particular volume, you do not point unrar directly at that volume. Instead, you target the first volume and specify the name of the file you want. The tool will parse through the stream across the volumes and extract only the designated file.

Command Syntax

To extract with full directory paths preserved:

unrar x archive.part01.rar "path/to/specific_file.ext"

To extract directly into the current directory without subfolders:

unrar e archive.part01.rar "path/to/specific_file.ext"

Note: Replace archive.part01.rar with the first volume name (or .rar in older naming schemes like .rar, .r00, .r01).

Attempting Extraction Starting from a Specific Volume

If you attempt to run unrar directly on a secondary volume of a solid set:

unrar x archive.part03.rar

unrar will recognize that the file is part of a multi-volume solid set and will immediately prompt you for the location of archive.part01.rar or fail with an error stating that previous volumes are required to initialize the dictionary.

Handling Damaged or Incomplete Sets (The -kb Flag)

If earlier volumes are missing and you must attempt to recover data from an isolated volume, use the -kb (Keep Broken) switch. This forces unrar to retain whatever data it can reconstruct, even if errors occur:

unrar x -kb archive.part03.rar

Outcome:

  • For non-solid archives, this successfully extracts any file that starts and ends entirely inside part03.rar.
  • For solid archives, extraction will usually fail or produce corrupted files, as the decompression algorithm cannot decode the stream without the missing dictionary history from previous volumes.

Summary of Best Practices

  1. Always start at Volume 1: Whenever extracting from multi-volume archives, point unrar to the first volume (.part01.rar or .rar).
  2. Specify file targets: Filter by file name at the end of the command rather than trying to split the archive manually.
  3. Keep all parts in the same directory: Ensure all volumes (.part01.rar, .part02.rar, etc.) are placed in the same working folder so unrar can transition between them automatically.
