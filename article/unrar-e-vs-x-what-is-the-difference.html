Unrar e vs x: What Is the Difference?

When extracting files with the command-line utility unrar, the primary difference between the e and x commands lies in how they handle directory structures. The e command extracts all files into a single flat directory, ignoring any internal folder hierarchy saved in the archive. In contrast, the x command extracts files while preserving their original directory structure and subfolders. Understanding this distinction is essential for preventing unwanted file overwrites and keeping your extracted data organized.

The unrar e Command: Extract Without Paths

The e stands for "extract." When you run this command, unrar pulls every file out of the RAR archive and places it directly into your target directory, stripping away any internal folders.

Syntax:

unrar e archive.rar

Key Characteristics:

  • Flattens the Archive: Regardless of how many subfolders exist inside archive.rar, every single file will be dumped into the current working directory (or the destination folder you specify).
  • Risk of Overwriting: If the archive contains two files with the same name located in different subdirectories (for example, folder1/readme.txt and folder2/readme.txt), unrar e will prompt you to overwrite or automatically overwrite the first file with the second.
  • Best Use Case: Use unrar e when you only need loose files from a nested structure, such as pulling a collection of images or documents out of multiple subfolders into one place.

The unrar x Command: Extract with Full Paths

The x stands for "eXtract with full path." This is generally the preferred command for unpacking archives because it reconstructs the exact directory tree stored by the creator.

Syntax:

unrar x archive.rar

Key Characteristics:

  • Preserves Hierarchy: If a file is stored inside backup/data/config.json inside the archive, unrar x creates the backup/data/ directories and places config.json inside them.
  • Safe Extraction: Because paths are maintained, files with identical names located in different directories will not conflict or overwrite each other.
  • Best Use Case: Use unrar x for software installations, backups, project repositories, or any archive where the relationship between folders and files must remain intact to function properly.

Quick Comparison

Feature unrar e unrar x
Directory Structure Discarded (Flattened) Preserved
Subfolders Created No Yes
Risk of Name Collisions High Low
Typical Use Case Bulk file dumping Backups and application data

For most extraction tasks, unrar x is the safer and more reliable choice, while unrar e is best reserved for situations where you explicitly want to remove nested folder structures.
