How to Check if a RAR File Is a Solid Archive

This guide explains how to determine whether a RAR archive is formatted as a solid archive using the unrar command-line tool. You will learn the exact command required to view the technical metadata of an archive, what specific output flags to search for, and how to filter the output for quick verification.

The Command to Inspect the Archive

To inspect the properties of a RAR file, use the technical listing command lt:

unrar lt archive.rar

The lt flag instructs unrar to display detailed technical information about the archive and the individual files inside it.

Identifying Solid Archive Status

When you run unrar lt archive.rar, look at the top section of the output before the file listing begins. This section displays archive-level details.

  1. Solid Archive: If the archive was created using solid compression, you will see a line indicating solid status, typically formatted as: 
    Details: solid
    or: 
    Solid: yes
  2. Non-Solid Archive: If the archive is non-solid, the solid flag will either be explicitly marked as no or completely absent from the archive header details.

Quick Verification Using Grep

If you only want a true/false confirmation without scrolling through the full file list, pipe the output into grep:

unrar lt archive.rar | grep -i "solid"

If the command returns a matching line (such as Details: solid or Solid: yes), the archive is solid. If the command outputs nothing, the archive is a standard, non-solid RAR file.
